# Help Generation Templates

## General Capability Overview

I can help you with comprehensive marketplace operations:

### 🛍️ Product Management
- Search products by name, price, category, location
- Add new products with descriptions and images
- Update prices, stock levels, and details
- Manage product variants and options

### 👤 User Operations
- View user profiles and ratings
- Check seller information and history
- Manage your account settings
- Follow/unfollow other users

### 📦 Orders & Transactions
- Create and track orders
- View order history and status
- Process payments and refunds
- Manage shipping information

### 🏠 Other Marketplace Features
- Property listings (real estate)
- Vehicle listings (cars, motorcycles)
- Job postings and applications
- Service provider listings
- Reviews and ratings
- Messages and notifications

### 🔍 Search Capabilities
- Full-text search across all content
- Filter by price, location, category
- Sort by relevance, price, date
- Location-based radius search

## Context-Specific Help

### For Product Searches
"I can help you find products by:
- Name or description
- Price range (e.g., 'under $50')
- Category (electronics, clothing, etc.)
- Location (near you or specific area)
- Seller ratings
- Availability status"

### For Order Management
"I can assist with orders by:
- Tracking current orders
- Viewing order history
- Checking delivery status
- Processing returns
- Contacting sellers"

### For User Accounts
"I can help with user accounts:
- View public profiles
- Check ratings and reviews
- See seller listings
- Manage follows
- View activity history"

## Quick Actions Menu

When user asks "what can you do?", present organized options:

1. **🔍 Search & Browse**
   - Find products
   - Browse categories
   - Check deals

2. **🛒 Buy & Sell**
   - Create listings
   - Make purchases
   - Manage inventory

3. **📊 Track & Manage**
   - Order tracking
   - Sales analytics
   - Account settings

4. **💬 Communicate**
   - Send messages
   - Leave reviews
   - Get support

## Error Recovery Help

When operations fail, offer alternatives:

"I couldn't complete that operation. Here's what you can try:
- [Alternative approach 1]
- [Alternative approach 2]
- [Simplified version of request]

Would you like me to try one of these instead?"
